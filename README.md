## 🌟 Executive Overview
**ProcureBot** is an autonomous back-office automation platform built for Operations and Finance teams. It replaces hundreds of hours of manual entry by parsing vendor invoices via neural optical character recognition (OCR), executing automated 3-way matching (Invoice ⇄ Purchase Order ⇄ Goods Receipt), and posting balanced journal entries directly into enterprise General Ledgers (SAP S/4HANA, NetSuite, Workday).
